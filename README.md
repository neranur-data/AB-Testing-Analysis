# A/B Testing Analysis: Maximum Bidding vs Average Bidding

## Project Overview
This project evaluates a one-month A/B experiment comparing two Facebook advertising bidding strategies for an e-commerce company. The goal is to determine whether **Average Bidding** differs from **Maximum Bidding** in average purchases.

## Business Problem
The company wants to decide whether to adopt the new Average Bidding strategy. The primary success metric is **Purchase**. Control uses Maximum Bidding; Test uses Average Bidding.

## Dataset
The Excel workbook contains two worksheets, **Control Group** and **Test Group**, each with 40 observations and four numerical columns:

| Column | Description |
| --- | --- |
| Impression | Number of ad impressions |
| Click | Number of ad clicks |
| Purchase | Number of purchases following ad clicks (primary metric) |
| Earning | Revenue generated by purchases |

The data are provided as a training case study; the Purchase values include decimals.

## Methods
1. Load and explore both worksheets using Pandas; check missing values and descriptive statistics.
2. Label and combine the groups using `pd.concat`.
3. Define a two-sided hypothesis: **H0:** mean Purchase is equal across groups; **H1:** mean Purchase differs.
4. Check normality separately using **Shapiro–Wilk** and variance homogeneity using **Levene's test**.
5. Compare Purchase means using an independent-samples **Student's t-test** (`equal_var=True`), at **α = 0.05**.
6. Interpret the statistical evidence and provide a business recommendation.

## Results

| Metric / test | Control (Maximum) | Test (Average) |
| --- | ---: | ---: |
| Observations | 40 | 40 |
| Mean Purchase | 550.89 | 582.11 |
| Purchase standard deviation | 134.11 | 161.15 |
| Shapiro–Wilk p-value | 0.5891 | 0.1541 |

| Comparison test | Statistic | p-value |
| --- | ---: | ---: |
| Levene's test | 2.6393 | 0.1083 |
| Independent-samples Student's t-test | -0.9416 | 0.3493 |

Average Bidding's observed mean Purchase is approximately **5.67% higher**, but the t-test does **not** find a statistically significant difference at α = 0.05. Failure to reject the null hypothesis does not demonstrate equivalence.

## Business Recommendation
Do **not** switch bidding strategies solely on these results. A follow-up experiment with a planned sample size and adequate statistical power may provide clearer evidence. Business decisions should also consider advertising costs, revenue, and profitability.
